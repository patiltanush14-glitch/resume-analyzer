# 🚀 AI Resume Analyzer

An intelligent web application that analyzes resumes and provides an **ATS score**, identifies **missing skills**, and gives **improvement suggestions**.

---

## 📌 Features

*  Upload resume (PDF format)
*  Extract text using PyPDF2
*  Generate ATS score
*  Show found skills
*  Highlight missing skills
*  Provide improvement suggestions
* 🌐 Deployed online using Render

---

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **PyPDF2**
* **HTML & CSS**
* **Render (Deployment)**
* **GitHub (Version Control)**
